# Stock BGM Pool

Source: Mixkit Free Stock Music

License notes:
- Mixkit states its free stock music can be used in video projects including social media platforms, YouTube, podcasts, websites, and online advertisements.
- Mixkit states attribution is appreciated but not required.
- These tracks are stored locally so the pipeline can select a BGM without calling Lyria.

Downloaded tracks:
- `mixkit_hip_hop_02.mp3` — Hip Hop 02 by Lily J — https://mixkit.co/free-stock-music/
- `mixkit_gimme_that_groove.mp3` — Gimme that Groove! by Michael Ramir C. — https://mixkit.co/free-stock-music/
- `mixkit_cat_walk.mp3` — Cat Walk by Arulo — https://mixkit.co/free-stock-music/
- `mixkit_villa_penthouse.mp3` — Villa Penthouse by Arulo — https://mixkit.co/free-stock-music/
- `mixkit_tech_house_vibes.mp3` — Tech House vibes by Alejandro Magana (A. M.) — https://mixkit.co/free-stock-music/

Runtime behavior:
- Default: choose one random local stock track per language.
- Set `MODOC_BGM_SOURCE=lyria` to force generated Lyria BGM.
